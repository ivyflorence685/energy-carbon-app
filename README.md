ENERGY CARBON APP
A simple web application to monitor household energy usage and estimate carbon emissions using a dashboard interface.

PROJECT OBJECTIVE 
The objective of this project is to help users understand their energy consumption patterns based on different rooms and appliances and analyze their carbon impact using visual charts and alerts.

FEATURES:
  -> Room-wise energy monitoring
  -> Appliance energy analysis
  -> Carbon emission estimation
  -> Interactive charts and graphs
  -> Smart alert system
  -> Day-wise filtering
  -> Simple and responsive UI

SOFTWARE USED:
  -> html
  -> css
  -> javascript
  -> python (flask)  
  -> Chart.js

-> The project uses a sample household energy consumption dataset for visualization and analysis.

FUTURE IMPROVEMENTS:
  -> Add database support
  -> Add login system
  -> Real-time IoT sensor integration
  -> Export reports
  -> AI-based energy recommendations
  -> Mobile application support

CONCLUSION:
This project helps visualize usage and carbon emissions is a simple and interactive way.It can be further improved into a smart energy management system in the future.
